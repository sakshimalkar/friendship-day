## ✨ Features

- **🎁 Interactive Gift Cards** - Clickable cards that reveal personalized messages.
- **🎞️ Memory Gallery** - A responsive grid displaying custom photos.
- **🎵 Background Music Player** - Embedded audio with play/pause controls.
- **💌 Surprise Love Letter** - A beautifully styled pop-up modal.
- **✨ Dynamic Animations** - Floating bubbles, sparkles, and rising hearts on interaction.
- **📱 Fully Responsive** - Works perfectly on desktops, tablets, and mobile devices.
- **🎨 Modern UI/UX** - Gradient backgrounds, custom fonts, and smooth hover effects.
